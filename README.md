# 家族修仙录

在浏览器中运行的中文文字策略模拟游戏。你经营一个修仙家族，它可能延续数百年，也可能一夜覆灭。家主会老会死，族人会长大、联姻、争权，没有谁能一直替你扛事。

> **当前进度：阶段 1（可玩核心）**，依据《开发规格 V3》第 21 章。尚未完成的功能见文末「已知缺口」，游戏界面中对应位置也有「未完成」标注。

## 运行方式

- 双击 `dist/family-xiuxian.html`，用最新版 Chrome 或 Edge 打开即可。也能在手机浏览器里玩。
- 只有一个文件，不需要联网，也不需要任何构建步骤。

## 操作说明

1. **开局**：先选出身，有坊市小族、没落世家、山野散修之后三种。姓氏和种子都可以留空，留空时随机生成。种子相同、决策相同，结果就逐位相同。
2. **回合**：一个回合是 5 年，分四个阶段：开年 → 家族安排 → 推进五年（内部逐年结算） → 家族纪事。
3. **差事**：每人的差事默认沿用上回合。系统只会高亮需要处理的人，比如新成年、伤愈或被撤职的族人，以及新入族的人。界面提供「按建议安排」和批量改派。
4. **决策面板**：重大事件会弹出决策面板。每个选项都写明成本、风险和可能结果；不可逆的选项需要二次确认。可以用数字键 1–9 直接选择。年度结算中途如果发生大事，推进会暂停，处理完后点「继续推进」，把本回合剩下的年份走完。
5. **突破**：炼气一至八层修满后自动晋升。筑基小瓶颈默认自动尝试。大关需要家主决定，决定前会列出成功率和每一项修正。
6. **家规**：继承制度、资源分配、对外政策三类。修改家规有代价：扣威望、分支有阻力，同类家规改完要冷却 4 个回合；新家规下回合才生效，第一个回合只发挥一半效果。
7. **可追溯**：带虚线的数值，悬停或点击都能看到成因分解。年代纪事里点开一条记录，可以看到它的前因和后果。

## 规则概要

| 系统 | 要点 |
| --- | --- |
| 境界与寿元 | 凡人 70；炼气 110；筑基 200/225/250；金丹 450/500/560。突破成功后寿元上限立即补足 |
| 修炼速度 | 境界基础值 × 灵根 × 资质 × 功法适配 × 洞府 × 丹药 × 差事 × 家规 × 年老/伤病 × 指点 |
| 突破 | 筑基大关基础成功率 35%，有筑基丹 +25%，没有则 −25%；另有资质、灵根、功法、洞府、护法、积累、失败次数等修正，结果限制在 5–85% |
| 遗传 | 按第 8 章公式：父母灵根得分影响子女灵根分布；资质 = 父母资质均值的一半 + 25 + 正态偏差 |
| 经济 | 灵田出灵谷和灵药，炼丹房把灵药加工成聚气丹，商铺出售库存。差事人手提供产出加成和基础产出。维护费随建筑等级累积，修士每年消耗灵石 |
| 入不敷出 | 灵石耗尽不会直接失败：商铺、洞府、炼丹房效率减半，族人忠诚下降，并触发「资金断裂」事件（可借贷、变卖产业或削减开支） |
| 家主与分支 | 家主有威望，嫡系和旁支各有支持度。指定继承人后的接受度分高、中、低三档；接受度低时会触发继承争议 |
| 自主行为 | 族人会按性格积攒私财、交好、起争执或提出请求。连续 3 个回合忠诚低于 30、并且有明确诱因的人可能出走，全族每回合最多走 1 人 |
| 外交与危机 | 阶段 3 实现。目前只有关系值，事件会改变它 |

## 存档

- 3 个手动槽位加 1 个自动存档。自动存档时机：每次操作后、推进中断时，以及关闭页面前（尽力保存一次）。
- 存储位置：优先用 IndexedDB（库名 `family-xiuxian`），不可用时降级为 localStorage。两者都不可用时，界面会提示改用导出。
- 导出可以下载 `.json` 文件，也可以复制成一段压缩文本（以 `FXZ1:` 开头）。导入同样支持选择文件或粘贴文本。
- 读档时依次检查：版本 → 校验和 → 结构 → 引用完整性。任何一步失败都会给出可读的错误提示，并且不会覆盖当前进度。

## 数值配置

所有数值、概率、名字库和文本模板都在 `src/core/config.js`，事件定义在 `src/core/events-data.js`。逻辑代码里不写死任何平衡数值。

## 开发与测试

```
src/core/   模拟核心（不访问 DOM、不调用 Math.random / Date.now，可在 Node 中无头运行）
src/ui/     界面与存储适配器
src/index.html  单文件模板
build.js    把 src/ 内联成 dist/family-xiuxian.html
test/       自动化测试、平衡报告、预设策略、界面冒烟测试
```

```bash
node build.js                 # 生成 dist/family-xiuxian.html
node test/run-tests.js        # 自动化测试（第 22 章检查项中阶段 1 可测的部分）
node test/run-tests.js --quick
node test/balance.js --seeds 40   # 平衡报告（第 18 章指标）
node test/ui-smoke.js         # 浏览器冒烟测试（需要 Playwright）
```
