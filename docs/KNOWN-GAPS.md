# 阶段进度与已知缺口（个人主角版）

依据《家族修仙录改造方案：个人主角》。家族经营玩法已整体删除，不做开宗立族。

## 阶段 1 · 主角最小循环（本阶段）

| 内容 | 状态 |
| --- | --- |
| 新存档结构（schemaVersion 2，世界数据库 + 主角），旧家族存档明确拒绝 | ✓ |
| 主角创建：三种出身、自定姓名性别、种子可复现 | ✓ |
| 世界生成：约 18 个地点与道路、7 个势力、约 80 个人物、坊市 | ✓ |
| 时间按天推进，跨月结算主角、跨年结算世界 | ✓ |
| 行动：修炼/闭关、突破、赶路、游历、打杂/差事、坊市买卖、服药、改修功法、静养、拜访、请教 | ✓ |
| 遭遇：妖兽、劫修、古修洞府，选项写明代价、风险、成功率构成 | ✓ |

| 主角身故的结局、生平与评定 | ✓ |
| 界面：开局、此刻、地图、人物、行囊与坊市、纪事、存档与设置；手机适配 | ✓ |
| 两条原则的统计检验（测试 9、10） | ✓ |
| 验收：长时间模拟无异常、同种子可复现、存读档一致（含待决事件时）、清单外行动一律拒绝 | ✓ 见 `test/out/test-summary.json` |

本阶段的已知缺口：
- 地图上所有地点一开局就全部可见（没有“未知之地”）；传闻只是文字，不会解锁什么。
- 人物之间（NPC 与 NPC）没有关系、恩怨和互动；NPC 不会主动找主角。
- 劫修被打败后只是结仇，暂时不会回来报复（长期因果在阶段 4）。
- 没有加入/离开势力的行动；宗门、家族的份例是固定数。
- 金丹需要凝丹灵物，坊市很少出现，现阶段几乎到不了金丹。
- 评定只看境界、足迹、胜场和知交，比较粗。
- 游戏名仍叫《家族修仙录》，待定。

## 阶段 2 · 世界数据库（下一阶段）

势力会自己行动（招人、结盟、争地盘）；关系网扩展到 NPC 之间，含师徒、道侣、仇敌；具体物品；秘密与知情者；剧情线结构；地图未知之地；加入或离开势力。

## 阶段 3 · AI 叙事 + 规则验证

DeepSeek 接入，生成结构化事件提案；效果白名单与境界上限；验证器；检定与结算；aiLog 记录与重放；自由文本输入解析；无 key 时回落模板。旧版 `src/ui/ai.js`（在分支 `claude/ai-head`）的调用、key 管理、超时回落、防编造校验会搬回来复用。

## 阶段 4 · 长期因果与大事

斗法公式细化、秘境、NPC 记仇报恩、秘密揭露、势力战争。

## 阶段 5 · 打磨

平衡校准、生平与结局、界面、AI 调用次数与成本控制。
